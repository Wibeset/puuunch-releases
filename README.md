Puuunch is a punch-in system disguised as a menu bar utility — not a dashboard,
not a productivity suite. Click the icon, type three letters of a project, press
return. You are on the clock in under two seconds, without ever leaving the
keyboard or opening a browser tab.

## How it works

- **Click the menu bar icon** — a centered command modal fades in over a blurred
  backdrop. Type to fuzzy-search a project, `↵` to punch in, or type a new name
  and `↵` to create it and start at once.
- **While you work** — the menu bar reads `Project Name`. Reopen the modal for a
  live timer and three one-tap actions: **Switch**, **Stop**, **Keep going**.
  Switching closes one session and opens the next, no confirmation.
- **Right-click the icon** — the week's **Timesheet**, where you review each day,
  add an entry by hand, and send the week for approval.

## Features

- **Two seconds, keyboard only** — fuzzy search, arrow keys, `↵`, `esc`. The
  modal is the entire daily surface.
- **It survives being offline** — sessions are written locally first and pushed
  to puuunch when the network comes back. A punch made on a plane is never lost.
- **An honest weekly view** — per-day totals, absences, and a week you can close
  and send for approval without opening the web app.
- **Invisible until needed** — no Dock icon, no window, no badge. The menu bar
  mark dims when nothing is running.
- **Light and dark** — follows your macOS appearance.

## Download

**[Download Puuunch for macOS →](https://puuun.ch/download/mac)** — requires
macOS 14 or later.

Every build here is signed with a Developer ID certificate and notarized by
Apple, so it opens without a Gatekeeper warning. Drag it to Applications and
click the mark in your menu bar.

You will need a [puuunch](https://puuun.ch) account to sign in — the app tracks
time against your organization's projects, and syncs what you log back to the web
app as time entries.
