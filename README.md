# puuunch — macOS

Builds of the **Puuunch** menu bar time tracker for macOS 14 or later.

**[Download the latest version](https://puuun.ch/download/mac)**

Every release here is signed with a Developer ID certificate and notarized by
Apple, so it opens without a Gatekeeper warning.

This repository holds the builds only — it exists so the download link can be a
stable, public URL. The application source lives elsewhere.

Questions and bug reports: <support@puuun.ch>
